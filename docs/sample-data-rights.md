# Sample data rights

Repository CSV fixtures and browser demo data are synthetic values created for software testing. They do not describe real people, patients, experiments, institutions, or published research and may be redistributed under the repository license.

Contributors must not add confidential, personal, clinical, export-controlled, or third-party research data without documented permission. A new sample must include its source, license/permission, intended use, and any required attribution. Prefer synthetic fixtures that preserve only the structural edge case being tested.

User-uploaded data remains user-controlled. Local mode stores it under the configured data directory and removes task data and artifacts on deletion or TTL cleanup. Remote operators are responsible for retention notices, access controls, backups, physical deletion guarantees, and applicable data-protection law.
